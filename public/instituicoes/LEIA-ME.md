# Logótipos das instituições parceiras

Coloque aqui os ficheiros oficiais, com estes nomes exactos:

| Ficheiro    | Instituição                                        |
| ----------- | -------------------------------------------------- |
| `acite.svg` | Academia de Ciências Sociais e Tecnologias (ACITE) |
| `isa.svg`   | Instituto Superior de Angola (ISA)                 |

SVG é preferível por ser vectorial. PNG com fundo transparente também serve —
nesse caso altere a extensão em `components/AboutPage.tsx`, na lista
`INSTITUICOES_PARCEIRAS`.

Enquanto os ficheiros não existirem, a interface mostra um monograma com a
sigla da instituição, no lugar exacto onde o logótipo vai ficar. Não é preciso
alterar código nenhum para os activar: basta o ficheiro estar cá.

Os logótipos são propriedade das respectivas instituições. Use apenas as
versões oficiais fornecidas por elas.
