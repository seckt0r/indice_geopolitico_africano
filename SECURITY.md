# Política de Segurança

## Versões com Suporte
As seguintes versões estão atualmente sendo mantidas com atualizações de segurança:

| Versão | Suportada          |
| -------| ------------------ |
| 1.0.x  | :white_check_mark: |

## Como relatar uma vulnerabilidade
Não abra uma *Issue* para relatar falhas de segurança críticas. Por favor, envie os detalhes diretamente aos administradores do repositório no email de segurança (se aplicável), ou contate a gestão atual do projeto.
