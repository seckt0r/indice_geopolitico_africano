# Guia de Contribuição

Obrigado por querer contribuir para o **Catálogo da Geopolítica de África**!

## Processo de Contribuição
1. Procure nas issues existentes se o problema ou funcionalidade já está sendo discutido.
2. Crie um fork do repositório.
3. Crie a sua branch: `git checkout -b feature/SuaSuperFeature`
4. Siga os padrões do `.gitmessage` configurado no projeto ao realizar seus commits. (Português/pt-BR)
5. Envie suas mudanças: `git push origin feature/SuaSuperFeature`
6. Abra um Pull Request e preencha as informações do template.

Por favor, garanta que suas modificações não "quebrem" o build passando no CI via Github Actions e que elas passem por qualquer regra de formatação configurada.
